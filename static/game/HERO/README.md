# H.E.R.O.

Atari 2600《H.E.R.O.》(Helicopter Emergency Rescue Operation, 1984) 的本地复刻。

**所有文件都在这个文件夹里，不需要再下载任何东西，也不需要联网。**

## 怎么玩

1. 双击 `play.bat`（会启动本地服务器并打开浏览器）
2. 或在本目录执行：

```bat
python -m http.server 8765
```

然后打开 http://127.0.0.1:8765/

直接双击 `index.html` 一般也可以玩；如果浏览器拦截音效或本地文件，请用 `play.bat`。

## 操作

| 键 | 作用 |
|---|---|
| ↑ / W | 螺旋桨飞行 |
| ← → / A D | 左右移动 |
| ↓ / X | 站在地上放炸药（立刻走开） |
| 空格 / Z | 头盔激光（打怪，也能慢慢切开落石墙） |
| P | 暂停 |
| M | 静音 |
| Esc | 回标题 |

手机浏览器会显示虚拟按键。

标题画面可选从第 1 / 5 / 9 / 13 / 17 关开始，对应原作 Game 1–5。

## 规则（按原作手册）

- 每关 6 根炸药，4 条命出发
- 炸墙 75 分，打怪 50 分，救人 1000 分
- 剩余炸药每根 50 分；剩余能量按关卡给奖励
- 每 20000 分加一条命（备用命最多 6）
- 100 万分任务结束
- 能量耗尽、岩浆、蜘蛛、蝙蝠、飞蛾、蛇、触手、自己的炸药都会丢命
- 灯被碰到或打中后，这一段矿井会变黑；炸药导火索能临时照亮
